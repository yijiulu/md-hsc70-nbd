# Simulation Setup & Force-Field Rationale

Every modelling decision for the Hsc70 NBD (`1KAX`) GROMACS pipeline is logged below alongside its experimental or literature basis and explicit caveats.

| Modelling Choice | Evidence Status | Rationale & Verification |
| :--- | :--- | :--- |
| Starting structure `1KAX` (`K71M`, `ATP·Mg²⁺·2K⁺`, `1.7 Å`) | Supported | Only bovine/human Hsc70 NBD crystal structure containing intact ATP with resolved active-site $\mathrm{K^+}$ ions (O'Brien *et al.*, 1996, PMID `8663302`). Bovine (`P19120`) and human (`P11142`) sequences are 100% identical across residues `1–394`. |
| Revert `M71K` via `PDBFixer` | Standard | Restores wild-type catalytic lysine; classical MD does not undergo hydrolysis, and post-equilibration `K71:NZ` sits `~5.0 Å` from $\gamma$-phosphate oxygens without steric clash. |
| Paired ATP/ADP start (`ADP` = delete $\gamma$-phosphate + insert water at `O3G`) | Supported | Eliminates starting-structure bias (`1KAX` vs `3HSC` $\mathrm{C\alpha}$ RMSD is `0.44 Å`). Across all 5 ADP-only Hsc70 crystal structures in RCSB (`1ATS`, `1NGA`, `1BA1`, `1QQO`, `6B1N`), 4/5 exhibit monodentate $\beta$-phosphate + 5 waters with a water `0.7–1.1 Å` from the former `O3G` site (Flaherty *et al.*, 1994). |
| Retain 2 active-site $\mathrm{K^+}$ (`K490`, `K491`); omit `K492` (site 3) | Supported / Caveat | Site-3 $\mathrm{K^+}$ appears only in `K71` mutants (`1KAX`, `1KAY`, `1KAZ`); all wild-type `K71` structures with resolved $\mathrm{K^+}$ (`1HPM`, `1BUP`, `2BUP`, `1QQM`, `1QQN`, `1QQO`) occupy site 3 with water (Wilbanks & McKay, 1995, PMID `7836458`). Caveat: Gołaś *et al.* (2015) included 3 $\mathrm{K^+}$ in ATP runs; bulk $\mathrm{K^+}$ entry at site 3 is tracked explicitly in `an_snap.py`. |
| Retain site-2 $\mathrm{K^+}$ (`K491`) in ADP state | Caveat | Matches Gołaś *et al.* (2015), where both $\mathrm{K^+}$ remained bound across `6 × 2 µs` ADP trajectories. Because `K2` bridges $\mathrm{P_i}$ in `1HPM`, keeping `K2` in $\mathrm{P_i}$-free ADP could make ADP more ATP-like; retention is monitored continuously in QC. |
| Retain first-shell crystal waters (`CWAT`) | Standard | First-shell octahedral waters around $\mathrm{Mg^{2+}}$ and $\mathrm{K^+}$ (`< 3.2 Å`) are preserved and restrained during equilibration. Because GROMACS permits `SETTLE` on only one molecule type (`SOL`), `CWAT` uses constrained `O–H` bonds with a flexible `H–O–H` angle (6–7 molecules total). |
| `AMBER ff19SB` + 4-point `OPC` + Li–Merz OPC ions (`0.15 M KCl`) | Supported / Caveat | `KCl` prevents $\mathrm{Na^+}$ substitution at site 1 (Wilbanks & McKay, 1995) and matches BMRB `26815` potassium-phosphate NMR conditions (Zuiderweg & Gestwicki, 2017, PMID `27699616`). $\mathrm{Mg^{2+}}$ uses Li–Merz 12-6 CM OPC parameters (Li *et al.*, 2020, PMID `32510956`); GROMACS lacks native 12-6-4 $r^{-4}$ ion terms, so inner-shell $\mathrm{Mg^{2+}}$ coordination is verified across full-system snapshots. |
| Meagher *et al.* (2003) ATP/ADP polyphosphate parameters | Supported | RHF/6-31+G* polyphosphate parameters + RESP charges (PMID `12759902`). Overlapping atom types were checked automatically against `amber19sb.ff/ffnonbonded.itp` for identical Lennard-Jones $(\sigma, \varepsilon)$; only the non-standard terminal oxygen type (`O3`) is appended via `LIG_atomtypes.itp`. |
| Cation-aware `PROPKA3` (`pH 7.0`) | Supported | Metal-free `PROPKA3` misassigns `Asp10`, `Asp199`, and `Asp206` as protonated; including $\mathrm{Mg^{2+}}$/$\mathrm{K^+}$ shifts their $\mathrm{p}K_a$ to `1.81 / 3.17 / 6.53` (ATP) and `0.33 / 1.01 / 5.62` (ADP), confirming deprotonated carboxylates. `build_system.sh` enforces charged Asp/Glu within `4.0 Å` of bound cations. |
| Dodecahedron box (`1.0 nm` padding), `300 K`, `1 bar`, `4 fs` HMR | Supported | Box vector `9.36 nm` exceeds molecular diameter (`6.4 nm`) + `2 × rcoulomb` (`2.0 nm`), verified via `pbc_min >= 17.8 Å`. Uses `v-rescale` thermostat, `c-rescale` barostat, `mass-repartition-factor = 3` (Hopkins *et al.*, 2015), `lincs-order = 6`, and `lincs-iter = 2`. |

## Known Limitations

- Subdomain reorientation in isolated Hsp70 NBD can involve microsecond timescales (Zhang & Zuiderweg, 2004, PMID `15232009`); `100–150 ns` replicas probe rapid local relaxation and docked-linker stability rather than complete equilibrium sampling of slow domain transitions.
- Full allosteric activation requires coupled NBD–linker–SBD interactions (Zhuravleva *et al.*, 2012, PMID `23217711`); isolated-NBD conclusions are strictly scoped to NBD-intrinsic responses.
